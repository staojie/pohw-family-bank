# PoHW 家庭题库

家庭自用的 PoHW 在线题库。原 PoHW 小学四至六年级 4078 题，加家庭语数英各200题、百科10类各100题，共5678题。

题库目录：`bank/`。应用填写目录地址：

`https://raw.githubusercontent.com/staojie/pohw-family-bank/main/bank/`

题库内容权利归各自权利人，不随 PoHW 代码的 MIT 许可证一并授权。原题来源与权利说明参见 https://github.com/jagerzhang/PoHW/blob/main/docs/DATA_SOURCES.md 。新增家庭题为AI编写练习，尚未经过逐题专家审校，不承诺教材全覆盖。百科为小学通用常识。

家庭版应用在线更新成功后缓存到本地，网络不可用时保留旧缓存及同版离线备用库。题库更新与APK更新互相独立。
